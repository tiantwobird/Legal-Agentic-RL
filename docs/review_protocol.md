# 人工复核指南（供独立法律领域审核者）

这份数据是**研究性质的 600 题数据集（300 train / 100 dev / 150 frozen test / 50 badcase）**，并不是已经完成独立律师/法律专家签字复核的数据集。

## 本次已经完成的检查
1. 模型助理逐题阅读法条和任务表述，人工构造每条示范结论、适用条件和证据缺口。
2. 机器检查 `source_evidence[].supporting_quote` 是源文件同一 `article_id` 对应正文的精确子串。
3. 比对源文件 `text_sha256` 与重新计算的哈希，检查 `version_id`、`effective_from` 与任务适用日期的形式一致性。
4. 核验 task ID、题目重复、训练/测试文件隔离、标签没有传给 Agent prompt。
5. 官方来源抽查包括人社部《劳动合同法》、官方部门《劳动争议调解仲裁法》、国务院《劳动合同法实施条例》以及最高人民法院对举证问题的案例说明。

**这些检查不能证明所有法条在真实案件中可以直接适用，也不能替代法律专业人士逐条审定。** 文本支持的一般规则，不必然等于事实适用结论已由权威机关确定。

## 对每个 task 的专家待审核项目
- [ ] 事实描述没有在适用日期之后发生；没有隐含事实或前提自相矛盾。
- [ ] `gold_article_ids` 是足以支持任务主要结论的相关法条；是否有同样合法但更优的法条需要增补。
- [ ] `expected_answer_points` 没有把应然条件写成确定案件结果，没有遗漏重要例外。
- [ ] `source_evidence` 的引用片段与具体结论之间存在实质支持，不仅仅是关键词一致。
- [ ] 新旧法、司法解释、上位法和特别法没有冲突；2024 年的效力状态得到二次核实。
- [ ] 不确定性任务的 `missing_facts` 足够，且没有强行要求唯一结论。
- [ ] 模拟事实不涉及可识别真实当事人，适合训练。
- [ ] 设置 `independent_expert_review` 为 APPROVED / REVISE / REJECT，并写明原因。

## 重要已知边界
- 全部任务统一到 2024-06-01 法律适用场景，以避免缺少历史版本及 2025-09-01 施行的劳动争议解释（二）产生时效冲突。真实案件可能涉及跨期间事实、地域性规定和裁判标准，暂不覆盖。
- 上传语料内一些《劳动法》旧条款若脱离后续规范，可能给出过时结论。本批不把《劳动法》第 36、62、82 条作为 Gold 标签。
- 部分案件可以有不止一种有效引用路径，`gold_article_ids` 仅作为经过阅读的一组参考证据，不能据此把所有额外引用判为错误。
- 训练/开发/测试/badcase 拆分（300/100/150/50）中，测试集为 150 题，仍不足以支撑强泛化结论，且法律问题族可能重叠。正式评估需按事实模板隔离的独立数据集。
